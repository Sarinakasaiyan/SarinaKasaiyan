### 🧠 فلسفه پژوهشی
من به **Neuro-AI** و **رابط‌های مغز-رایانه (BCI)** اختصاص دارم. معماری‌های یادگیری عمیق قابل تفسیر را برای رمزگشایی حالات شناختی پیچیده از بیوسیگنال‌های غیرتهاجمی توسعه می‌دهم.
